# KPP single-cell analysis code

This repository contains the analysis code associated with the manuscript
on the peripheral immune landscape of Klebsiella pneumoniae pneumonia.

## Notebooks

- `01_Figure_1_2_analysis.ipynb`: analyses related to Figures 1–2
  and Supplementary Figures S1–S6.
- `02_Figure_3_4_analysis.ipynb`: analyses related to Figures 3–4
  and Supplementary Figures S7–S10.
- `03_Figure_5_6_analysis.ipynb`: analyses related to Figures 5–6
  and Supplementary Figures S11–S13.

## Data availability

Newly generated sequencing data are deposited in OMIX under accession
OMIX014353. Public datasets and accession numbers are described in the
manuscript and Supplementary Table S1.

## Software

The analyses were performed primarily using Python, Scanpy, and related
single-cell analysis packages. Cell–cell interaction analyses were
performed using CellPhoneDB.

## Notes

Users should modify input and output paths according to their local
computing environment. Raw sequencing data and identifiable clinical
information are not included in this repository.
